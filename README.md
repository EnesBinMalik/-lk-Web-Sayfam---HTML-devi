# İlk Web Sayfam - HTML Ödevi

![İlk Web Sayfam - HTML Ödevi — rozet](docs/rozet.svg)

> **Veri analizi · modelleme** — tasarım ve geliştirme: **Enes Öztürk**

---

HTML ile ilk web sayfası ödevi: Başlık, Hakkımda, neler yaptığım, hobilerim ve yorum satırlarıyla zenginleştirilmiş canlı web sayfası ve kod görüntüleyici.

## Öne çıkanlar

- Veri temizleme ve hazırlık
- İstatistiksel özet ve görselleştirme
- Modelleme ve tahmin adımları
- Yönetici özeti ve rapor görünümü

## Kurulum ve çalıştırma

```bash
npm install
npm run dev        # http://localhost:3000
```

| Komut | Not |
| --- | --- |
| `npm install` | bağımlılıklar |
| `npm run dev` | geliştirme sunucusu |
| `npm run build` | üretim derlemesi |

## Proje yapısı
